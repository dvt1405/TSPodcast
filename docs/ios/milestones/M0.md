### 3.1 Module và toolchain

- Đường dẫn `shared/`, Gradle path `:shared`, package gốc `tss.t.shared`, framework `baseName = "Shared"`, `isStatic = true`.
- Target Android: ưu tiên plugin `com.android.kotlin.multiplatform.library` (AGP 8.13.2 đã có) với `namespace = "tss.t.shared"`, `compileSdk`/`minSdk` lấy từ version catalog. Nếu plugin này xung đột với AGP/Kotlin hiện có thì dùng `androidTarget()` + `com.android.library`. Ghi lựa chọn vào `progress.md`.
- **Kotlin:** thử giữ `kotlin = "2.2.0"` của repo trước. Chỉ nâng khi Kotlin/Native 2.2.0 không link được với Xcode 26.3 SDK hoặc thư viện cần bản mới hơn. Khi nâng thì chọn bản **thấp nhất** chạy được, nâng `ksp` cho khớp (compose-compiler, serialization, parcelize dùng chung `version.ref = "kotlin"` nên tự đổi theo), rồi chạy lại `./gradlew :app:assembleDebug`. Cảnh báo "Xcode version not tested" thì tắt bằng `kotlin.apple.xcodeCompatibility.nowarn=true` trong `shared/gradle.properties`, không đụng `gradle.properties` gốc.
- **SKIE:** không bắt buộc ở M0. Chỉ thêm nếu changelog SKIE liệt kê đúng bản Kotlin đã chọn **và** build pass. Nếu không, Swift gọi `suspend fun` qua bridge async có sẵn của Kotlin/Native (completion handler → `async throws`). Ghi lý do vào `progress.md`.
- File Android được phép đổi: `settings.gradle.kts` (`include(":shared")`), `gradle/libs.versions.toml` (thêm entry; nâng Kotlin/KSP chỉ theo luật trên). Nếu Gradle báo "plugin is already on the classpath with an unknown version" thì được thêm **đúng** các dòng `alias(libs.plugins.kotlin.multiplatform) apply false` / `alias(libs.plugins.android.kotlin.multiplatform.library) apply false` vào `build.gradle.kts` gốc, và phải ghi vào `progress.md`. Không sửa file nào khác dưới `app/`, `core/`, `coreApi/`, `podcasts/`, `securedToken/`, `shared*/` (trừ `sharedKmp/` bị xoá), `feature*/`, `ads*/`, `hazeAndroid/`, `samples/`.

### 3.2 Model (features-spec §6, `coreApi/.../models`)

- `@Serializable` cho `Podcast`, `Feed`, `Episode`, `LiveEpisode`, `CategoryRes` (+ `Category{id, name, isFavourite?}`), `TrendingPodcastRes{count, feeds→items, max}`, `LiveResponse{count, items, max}`, `SearchResponse{count, feeds, query}`, `EpisodeResponse{count, items, liveItems?, query?}`, `PodcastByFeedIdRes{feed, query{id}}` và các kiểu lồng mà các model này dùng (`Person`, `PodcastTranscript`, `Soundbite`, `SocialInteract`, `Value`, `Funding`).
- `Json { ignoreUnknownKeys = true; explicitNulls = false; coerceInputValues = true }`. **Mọi field không có trong mọi response phải nullable hoặc có default**: response trending chỉ có `id, url, title, description, author, image, artwork, newestItemPublishTime, itunesId, trendScore, language, categories` (xem `podcasts/src/debug/assets/Trending.json`), không có `feedId`, `explicit`, `feedImage`.
- Kiểu `explicit` khác nhau: `Feed.explicit` là `Boolean`, `Podcast/Episode/LiveEpisode.explicit` là `Int` (bài học `GetMusicFeeds`).
- `categories` là `Map<String, String>?`. **Không** chép `MapStringStringJsonConverter`: converter này gọi `getAsJsonObject("categories")` trên chính giá trị field nên luôn trả `null`. Shared phải parse được object `{"1":"Arts"}` thành map.
- Không mang `cachedAt`, `@Entity`, `@Parcelize`, Gson annotation sang. `Podcast.default`/`Episode.default` (dùng `SimpleDateFormat`) không cần.
- Giữ `Podcast.fromFeed(feed)` và `Episode.getImageUrl()` (image đã trim, rỗng thì dùng `feedImage`).

### 3.3 Network, credentials, lỗi (architecture §3.2, §5; `NetworkModule.provideClient`, `securedtoken.cpp`)

- `interface CredentialsProvider { val baseUrl: String; val apiKey: String; val apiSecret: String; val userAgent: String }`.
- `PodcastIndexAuth(credentials, clock)` tạo **đúng 4 header** với **một** timestamp duy nhất (giây):
  `X-Auth-Date = t`, `X-Auth-Key = apiKey`, `Authorization = sha1(apiKey + apiSecret + t)` hex chữ thường, `User-Agent = userAgent`. SHA-1 bằng Okio. Bản C++ gọi `now()` hai lần; shared **không** được làm vậy.
- Thiếu credentials (bất kỳ giá trị nào rỗng/blank, hoặc còn nguyên chuỗi chưa thay `$(`) → mọi lời gọi trả `TSDataState.Error(MissingCredentialsException)` (hoặc `AppError.MissingCredentials` bọc trong exception) **không gửi request**, không ném ra ngoài, không `fatalError`/crash.
- `safeApiCall {}` thay `TSDataStateCallAdapterFactory`: 2xx + body parse được → `Success`; HTTP lỗi → `Error(PodcastIndexHttpException(code, body))` (tương đương `TSExceptions(errorCode, description)`); lỗi IO/timeout/parse → `Error(cause)`; **rethrow `CancellationException`**.
- Engine: OkHttp ở `androidMain`, Darwin ở `iosMain`, `MockEngine` trong test. `HttpTimeout` 20 s. **Không** cài `HttpRequestRetry` toàn cục (snippet ở architecture §3.2 lệch với Android): retry chỉ nằm ở E10/E11 (§3.5).
- Tham số `null` thì **không gửi** lên query. `cat`/`notcat` rỗng cũng không gửi.

### 3.4 Blacklist (`BlacklistRepositoryImpl`, features-spec §2)

- Nguồn: `ConfigAPI.getString("ts_podcast_black_list")` nếu trả JSON hợp lệ dạng `{feedId:[..], filterText:[..]}`; nếu `null`/không parse được thì dùng asset `coreApi/src/main/assets/blacklist.json`. Remote **thay thế** asset (không gộp), giống Android.
- Asset phải lấy từ **chính file** `coreApi/src/main/assets/blacklist.json` (ví dụ task Gradle sinh source Kotlin chứa nội dung file), không chép tay sang chỗ khác. Cách tương tự cho `categories.json` (fallback E9). Lý do: framework iOS là static nên resource không tự đi kèm; một nguồn duy nhất thì không lệch với Android.
- `interface ConfigAPI` trong `commonMain` chỉ cần `getString(key)` (và `getBoolean` nếu tiện). M0 Swift truyền implementation trả `nil`. Có `reload()` để sau này gọi lại khi Remote Config activate.
- Matching: `isInBlacklist(id)` so khớp chuỗi id; `isContainKeywordsBlacklist(text, filterSpace)` = `text.lowercase()` chứa một keyword. **[Sửa]** `filterSpace = true` phải thực sự bỏ khoảng trắng (Android bỏ kết quả `replace`).
- **[Sửa]** Android nạp blacklist bất đồng bộ trong `init`, nên request đầu tiên có thể chưa được lọc. Shared phải nạp xong trước lần lọc đầu tiên.
- Luật áp dụng theo endpoint (lấy từ code Android, hợp của repository + use case):

  Sau khi lọc, `count` = số item còn lại.
