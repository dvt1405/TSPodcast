### 3.2 Logic có unit test: `UpNextPanelState` + `UpNextPeek`

File `iosApp/TSPodcast/Player/UpNextPanelState.swift`, value type thuần (không import SwiftUI view, chỉ `CoreGraphics`/`Foundation`), `Sendable`, `Equatable`. PlayerView giữ nó trong `@State`.

- `enum Mode { case collapsed, expanded }`, `mode` mặc định `.collapsed`.
- `travel: CGFloat` = khoảng cách (pt) giữa đỉnh panel khi peek và khi mở; PlayerView cập nhật từ layout. `travel <= 0` (chưa đo) không được crash/chia cho 0: chỉ luật vận tốc, tap và nút áp dụng.
- `offset(forDrag dy: CGFloat) -> CGFloat`: độ dời của đỉnh panel so với vị trí mở (0 = mở hết, `travel` = peek). Collapsed: `travel + clamp(dy, −travel, 0)`; expanded: `clamp(dy, 0, travel)`. `dy` dương = kéo xuống.
- `mutating func endDrag(translation dy: CGFloat, velocity vy: CGFloat)` (pt, pt/s; `DragGesture.Value.velocity` có từ iOS 17):
  - `|vy| ≥ 1000`: hướng vận tốc thắng (`vy < 0` → expanded, `vy > 0` → collapsed).
  - Ngược lại, từ collapsed: expanded nếu `−dy ≥ 0.4 × travel`; từ expanded: collapsed nếu `dy ≥ 0.2 × travel`; không thì giữ nguyên. (Ngưỡng 40 %/20 %/1000 lấy từ `SlideArea.flingSlideAreaState`.)
- `expand()` (nút playlist, tap header khi peek), `collapse()`, `toggle()` (tap header), `didSelectItem()` → collapsed, `queueDidChange(count:)` → collapsed khi `count == 0`.
- `UpNextPeek.rows(queueCount: Int, currentIndex: Int, maxRows: Int) -> [Int]`: chỉ số các dòng peek = `[currentIndex, currentIndex + 1]` cắt theo `maxRows` và biên queue; queue rỗng hoặc index ngoài biên → `[]` (khi đó không vẽ panel).
- `UpNextPeek.maxRows(isAccessibilitySize: Bool, isCompactHeight: Bool) -> Int`: mặc định 2; Dynamic Type cỡ accessibility **hoặc** chiều cao compact (iPhone ngang) → 1.

### 3.4 Một chỗ cho API iOS 26: `Design/Glass.swift`

- `enum GlassSurfaceKind { case glass, material, opaque }` + `struct GlassSurfaceStyle { kind; showsBorder }` + hàm thuần `GlassSurfaceStyle.resolve(isLiquidGlassAvailable: Bool, reduceTransparency: Bool, increasedContrast: Bool) -> GlassSurfaceStyle`: Reduce Transparency → `.opaque` (mọi OS); không thì iOS 26 → `.glass`, thấp hơn → `.material`; `showsBorder = increasedContrast`. Có unit test.
- Modifier `glassSurface(in shape:, tint: Color? = nil, interactive: Bool = false)`: đọc `accessibilityReduceTransparency`, `colorSchemeContrast`, gọi `resolve`, vẽ `.glassEffect(...)` (26) / `.regularMaterial` / `Color(.secondarySystemBackground)` + viền `Color.primary.opacity(0.35)` 1 pt khi `showsBorder`.
- `GlassGroup(spacing:) { … }`: `GlassEffectContainer` trên 26, `Group` ở dưới.
- Button style helper: `.glassButton()` (26: `.glass`; dưới: `.bordered`), `.glassProminentButton(tint:)` (26: `.glassProminent` + tint; dưới: `.borderedProminent` + tint), `.glassCircleButton()` cho nút tròn (26: `.glass` + `.buttonBorderShape(.circle)`; dưới: `.plain` như M3).
- Helper cho shell: `tabBarMinimizesOnScroll()` (26: `.tabBarMinimizeBehavior(.onScrollDown)`), `bottomBar { }` / `topBar { }` (26: `safeAreaBar`; dưới: `safeAreaInset` + nền hiện tại).
- `MiniPlayerSlot.swift` giữ phần `tabViewBottomAccessory` và thêm hàm thuần `MiniPlayerLayout.resolve(isInlineAccessory: Bool, isAccessibilitySize: Bool) -> MiniPlayerLayout` (`.regular` / `.compact`; inline **hoặc** cỡ accessibility → `.compact`), có unit test.
- Luật kiểm được: các token `glassEffect`, `GlassEffectContainer`, `.glass`, `.glassProminent`, `tabBarMinimizeBehavior`, `tabViewBottomAccessory`, `safeAreaBar`, `scrollEdgeEffect`, `backgroundExtensionEffect` **chỉ** xuất hiện trong `Design/Glass.swift` và `Main/MiniPlayerSlot.swift`. View khác chỉ gọi helper. Compiler (deployment target 17) bắt mọi lời gọi chưa gate.

## 4. Quyết định kỹ thuật (developer không cần hỏi lại)

1. **PlayerView** dựng lại thành: `ZStack { PlayerBackground; VStack { hàng nút đóng; artwork (co giãn); tiêu đề; progress; controls; error?; Color.clear cao bằng chiều cao peek đo được } ; UpNextPanel (overlay căn đáy) }`. Panel ở peek chiếm đúng vùng `Color.clear` cuối VStack, nên không thể đè lên controls; khi mở panel dời lên theo `UpNextPanelState.offset`. Đo bằng `onGeometryChange` (có từ iOS 16 khi build bằng Xcode 16+). Animation: `.spring(duration: 0.35)`; Reduce Motion → `.easeInOut(duration: 0.2)` không nảy.
2. Gesture: `DragGesture(minimumDistance: 8)` chỉ gắn trên **header** của panel (grabber + tiêu đề + dòng peek). Khi mở, danh sách cuộn bình thường; thu bằng kéo header, tap header, chọn item, escape. (Không cài đặt "kéo list ở đỉnh để thu" của Android — phức tạp, dễ xung đột với cuộn; ghi trong progress.)
3. `UpNextSheet.swift` đổi thành `UpNextPanel.swift` (`UpNextPanel` + `UpNextRow` dùng chung + `UpNextList`). Không còn `.sheet` hay `presentationDetents` cho Up next. `PlayerControlsView.openPlaylist` gọi `panel.expand()`.
